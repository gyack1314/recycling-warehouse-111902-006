# 原始资料契约

所有机构、车辆、单据和设备均为本地合成，不来自新闻中的真实企业，也不声称新闻发生过这些事件。

两流event/revision定义来源修订，revision按同一event递增并全量替代，cancelled声明撤回。trip只在origin站点命名空间有效。arrival_ref/departure_ref可为null；有显式引用的一方限定对端event，另一方若也明确引用则须互相一致。双方未给引用时仅按origin/trip/lot和时间范围形成候选，不赋予隐含优先次序。lot须一致；允许arrival时间在departure后0至48小时，越界或多候选保留待核实，不将最近者作为隐含规则。
progress逐流逐分区给出已覆盖的事件时间through，允许相同前沿重报，倒退是来源异常。idle声明暂停参与本轮等待，恢复active后不能假定已覆盖其他分区的进度。前沿之后仍可有迟到原件或修订，覆盖前沿不表示业务事实永不更正。暂无匹配是观察状态，非删除原件许可。
未来程序可配置等待口径，但应记录它及所用分区前沿，明确哪些结论已完成等待、哪些仍候选。样本是可逐步投递的输入记录，没有预生成运输事实。

seed.json与同名Parquet保存相同的输入值，actions.json中的后续动作尚未处理。inventory.json只校验原件物理完整性，不是仓库目录或业务结论。所有后续仓表与接口均待开发，源码不规定其架构。
